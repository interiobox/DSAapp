---
name: Assignment row responsiveness
description: Responsive layout preference for drawing assignment rows.
---

Desktop assignment controls should remain on one line without taking disproportionate width; mobile may retain the compact stacked layout.

**Why:** The assignment page is used primarily as a dense desktop register, while the existing mobile layout was considered usable.

**How to apply:** Preserve the drawing-first grid proportions and constrain only the desktop control group with nowrap and compact button sizing.
